# Sync Changelog

Use when cutting or checking a release.

- Read current version/tag and `CHANGELOG.md`.
- Ensure the released version has a dated section.
- Ensure the next snapshot remains under `Unreleased`.
- Keep entries concise and commit with `docs: update changelog for <version>`.
